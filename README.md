# Desi Chhora 🪕

## Project Description

Desi Chhora is a terminal-based Python assistant designed to provide multiple interactive features through a simple command-line menu.

The program provides:

- Baat-Cheet (basic conversation)
- Calculator
- Prime Number Check
- Maximum / Minimum Number
- Quiz
- Date & Time
- Help menu
- Exit option

## Requirements

- Python 3.x
- No external Python libraries are required.

## How to Run

1. Install Python 3.x on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
